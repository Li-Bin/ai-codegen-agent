# IFFT 互動式訊號還原模擬器 — 介面協定 v1.2

> **v1.2 修訂（2026-08-16，實測校準）**
> 判準端測試套件已依本協定實作完成，並以正確參考實作＋4 組突變測試驗證。
> 過程中實測推翻了 §5.1 的一個數字：
> 1. **RTOL_LEAKY 由 0.05 修正為 0.16**。T-06 參數下正確實作的實測洩漏誤差為 0.1156，原上限 0.05 會把正確實作誤判為 fail。
> 2. T-06 改為**雙邊界限**，新增 `RTOL_LEAK_MIN = 0.02`：下限擋「偷改參數成對齊 bin」的作弊，上限（依失敗模式校準：no-op 0.283、只除一 bin 0.179、濾錯目標 0.755）擋濾波失效。
> 3. 新增 `RTOL_EXACT = 1e-9`：Parseval 與線性屬**尺度相依**恆等式，能量隨振幅平方與 N 成長，絕對容差會在大振幅下誤判——改用相對容差。ATOL_EXACT 的適用範圍收窄為單位尺度的往返測試。

> **v1.1 修訂（2026-08-16，已對 PyPI／官方文件查證）**
> 1. §5.2 套件表補上實際版本、授權，並列出**易混淆的錯誤套件名**。
> 2. §6.1 明訂 widget MUST 以 **key** 定址，不得以索引定址（官方文件已確認支援 key 取得）。
> 3. T-11 改寫：原本的「斷言 chart 元件存在」降級，因 AppTest 對圖表元件的原生支援未經確認；改以 `at.exception` 為主斷言，並新增 T-11b 以 `st.metric` 驗證 UI 確實接到 core 的計算結果。

> 本文件是給實作端（AI agent 或人）的**契約**，不是教學。
> 凡標記 **MUST** 的條款不得更動；標記 **SHOULD** 的可在說明理由後調整。

## 0. 決策紀錄（先讀，避免實作端「自作聰明」）

| # | 決策 | 理由 | 影響範圍 |
|---|---|---|---|
| D-1 | UI 選 **Streamlit**，PyQt 為備案 | Streamlit 內建 `streamlit.testing.v1.AppTest`，可在無顯示器的 CI 上做 headless UI 測試；PyQt 需 `pytest-qt` +虛擬 X server。 | 只影響 `ifft_sim/ui/`，core 不受影響 |
| D-2 | 頻域一律用 `numpy.fft.rfft` / `irfft`，**不用** `fft` / `ifft` | 對實數訊號，`rfft` 只回傳單邊頻譜。若用雙邊 `fft` 後把某些 bin 歸零，會破壞 Hermitian 對稱性，`ifft` 出來帶虛部殘留，得再 `.real` 硬砍——那是掩蓋錯誤，不是解法。`irfft` 從結構上保證輸出為實數。 | `core/spectrum.py`、測試 T-02 |
| D-3 | `sample_rate_hz` **必須外顯**為參數 | 題目只給「主訊號頻率／雜訊頻率／取樣點數」三項，但少了取樣率，時間軸無定義、Nyquist 無法檢查、頻率解析度 Δf 也算不出來。UI 可給預設值收在 advanced 區塊，但 core API 一定要有。 | `SignalSpec`、UI 版面 |
| D-4 | core 層**禁止** import 任何 UI／繪圖套件 | 讓核心邏輯可在純 CPU、無 GUI 環境測試；也逼實作端把運算與呈現分離。此條由測試 T-10 強制執行。 | 全專案 |
| D-5 | 數值容差寫死在協定裡，不由實作端自訂 | AI agent 最常見的失敗是「測試寫得比實作鬆」，湊過 green。容差集中定義於 §5.1。 | 全測試 |

## 2. 資料型別（`core/types.py`，MUST）

```python
from dataclasses import dataclass
import numpy as np
from numpy.typing import NDArray

class SimulatorError(ValueError):
    """本套件所有可預期錯誤的基底類別。"""

class InvalidParameterError(SimulatorError):
    """參數超出定義域（負頻率、N 太小等）。"""

class NyquistViolationError(SimulatorError):
    """sample_rate_hz <= 2 * max(訊號頻率)。"""


@dataclass(frozen=True)
class SignalSpec:
    main_freq_hz: float          # > 0
    noise_freq_hz: float         # > 0
    n_samples: int               # >= 8
    sample_rate_hz: float        # > 0，且須滿足 Nyquist
    main_amp: float = 1.0        # > 0
    noise_amp: float = 0.3       # >= 0
    main_phase_rad: float = 0.0
    noise_phase_rad: float = 0.0
    gaussian_sigma: float = 0.0  # >= 0，白噪標準差
    seed: int | None = None      # 白噪的亂數種子

    def __post_init__(self) -> None:
        """MUST 在此完成全部驗證，見 §4。"""

    @property
    def duration_s(self) -> float:      # n_samples / sample_rate_hz
        ...

    @property
    def freq_resolution_hz(self) -> float:   # Δf = sample_rate_hz / n_samples
        ...


@dataclass(frozen=True)
class SignalBundle:
    t: NDArray[np.float64]        # shape (N,)，t[0] == 0.0
    clean: NDArray[np.float64]    # 只有主訊號
    noise: NDArray[np.float64]    # 只有雜訊（弦波 + 可選白噪）
    noisy: NDArray[np.float64]    # clean + noise，恆等式 MUST 成立


@dataclass(frozen=True)
class Spectrum:
    freqs: NDArray[np.float64]        # shape (N//2 + 1,)，來自 rfftfreq
    coeffs: NDArray[np.complex128]    # shape (N//2 + 1,)，來自 rfft
    n_samples: int                    # 原始 N，irfft 還原長度時要用
    sample_rate_hz: float
```

**不可變性 MUST**：`Spectrum` 的任何轉換函式一律回傳**新物件**，不得就地修改 `coeffs`。

## 3. 核心 API（MUST，簽章不得更動）

### 3.1 `core/signal_gen.py`

```python
def generate(spec: SignalSpec) -> SignalBundle:
    """
    t[n]     = n / fs,  n = 0..N-1
    clean[n] = A_main  * sin(2π f_main  t[n] + φ_main)
    tone[n]  = A_noise * sin(2π f_noise t[n] + φ_noise)
    white[n] = N(0, σ²)，僅在 σ > 0 時產生，並以 spec.seed 建立
               np.random.default_rng(seed)（MUST 用 Generator，不用 np.random.*）
    noise    = tone + white
    noisy    = clean + noise
    """
```

### 3.2 `core/spectrum.py`

```python
def forward(x: NDArray[np.float64], sample_rate_hz: float) -> Spectrum:
    """np.fft.rfft(x) + np.fft.rfftfreq(len(x), 1/fs)。x 非 1-D 或長度 < 8 → InvalidParameterError。"""

def suppress_bands(
    spectrum: Spectrum,
    bands: Sequence[tuple[float, float]],
    mode: Literal["notch", "bandpass"] = "notch",
) -> Spectrum:
    """
    以 freqs 為準選出落在任一 [lo, hi]（閉區間）內的 bin。
    mode="notch"    → 選中的 bin 歸零
    mode="bandpass" → 未選中的 bin 歸零
    bands 為空 list：notch 回傳等值副本；bandpass 回傳全零 coeffs。
    任一 lo > hi 或 lo < 0 → InvalidParameterError。
    """

def suppress_tone(spectrum: Spectrum, center_hz: float, bandwidth_hz: float | None = None) -> Spectrum:
    """
    便利包裝：bandwidth 預設為 1.5 * Δf（Δf = fs / n_samples），
    等價於 suppress_bands(spectrum, [(c - bw/2, c + bw/2)], "notch")。
    """

def reconstruct(spectrum: Spectrum) -> NDArray[np.float64]:
    """np.fft.irfft(coeffs, n=spectrum.n_samples)。回傳 dtype MUST 為 float64，長度 MUST == n_samples。"""
```

### 3.3 `core/metrics.py`

```python
def rmse(a: NDArray[np.float64], b: NDArray[np.float64]) -> float:
    """長度不一致 → InvalidParameterError。"""

def snr_db(signal: NDArray[np.float64], noise: NDArray[np.float64]) -> float:
    """10 * log10(P_signal / P_noise)；P_noise == 0 → 回傳 float('inf')。"""

def peak_frequency(spectrum: Spectrum, ignore_dc: bool = True) -> float:
    """|coeffs| 最大者對應的 freqs 值；ignore_dc=True 時跳過 index 0。"""

def band_energy(spectrum: Spectrum, lo_hz: float, hi_hz: float) -> float:
    """該頻帶內 |coeffs|² 之和。"""
```

## 4. 參數驗證表（MUST，逐條對應測試）

| 條件 | 例外 |
|---|---|

## 5. 測試協定

### 5.1 容差常數（MUST 定義於 `tests/conftest.py`，測試只准引用不准就地寫死）

```python
ATOL_EXACT    = 1e-12  # 單位尺度訊號的 FFT 往返（實測 ~1e-16，留四個數量級）
RTOL_EXACT    = 1e-9   # 尺度相依精確恆等式：Parseval、線性（相對容差，理由見 v1.2 修訂）
ATOL_ALIGNED  = 1e-10  # 頻率對齊 bin 時的濾除還原誤差（實測 ~5e-15）
RTOL_LEAK_MIN = 0.02   # 洩漏誤差下限（× main_amp）——誤差趨近零代表參數被改成對齊 bin
RTOL_LEAKY    = 0.16   # 洩漏誤差上限（× main_amp）——實測正確值 0.1156；
                       # no-op 0.283 / 只除一 bin 0.179 / 濾錯目標 0.755 全數超標
```

## 7. 附錄：測試風格參考實作（實作端 MUST 沿用此風格）

```python
# tests/test_spectrum.py
import numpy as np
import pytest
from numpy.testing import assert_allclose

from ifft_sim.core.signal_gen import generate
from ifft_sim.core.spectrum import forward, reconstruct, suppress_tone
from ifft_sim.core.types import SignalSpec
from ifft_sim.core.metrics import rmse
from tests.conftest import ATOL_EXACT, ATOL_ALIGNED, RTOL_LEAK_MIN, RTOL_LEAKY


def make_spec(**kw) -> SignalSpec:
    base = dict(
        main_freq_hz=50.0, noise_freq_hz=125.0,
        n_samples=512, sample_rate_hz=1000.0,
        main_amp=1.0, noise_amp=0.4,
    )
    return SignalSpec(**{**base, **kw})


@pytest.mark.parametrize("n", [64, 128, 255, 512, 1023])
def test_T01_roundtrip_is_identity(n):
    """T-01: irfft ∘ rfft 必須是恆等映射（含奇數長度）。"""
    rng = np.random.default_rng(0)
    x = rng.standard_normal(n)
    assert_allclose(reconstruct(forward(x, 1000.0)), x, atol=ATOL_EXACT, rtol=0)


@pytest.mark.parametrize("n", [512, 1023])
def test_T02_reconstruction_is_real_float64(n):
    """T-02: 用 rfft/irfft 的結構性保證，輸出不得帶虛部。"""
    out = reconstruct(forward(np.random.default_rng(1).standard_normal(n), 1000.0))
    assert out.dtype == np.float64
    assert out.shape == (n,)


def test_T05_notch_removes_bin_aligned_noise():
    """T-05: 兩個頻率都落在 bin 上時，陷波後應精確還原主訊號。"""
    spec = make_spec()                     # Δf = 1000/512；50 與 125 皆為其整數倍附近
    df = spec.freq_resolution_hz
    spec = make_spec(
        main_freq_hz=round(50 / df) * df,
        noise_freq_hz=round(125 / df) * df,
    )
    b = generate(spec)
    filtered = suppress_tone(forward(b.noisy, spec.sample_rate_hz), spec.noise_freq_hz)
    assert rmse(reconstruct(filtered), b.clean) < ATOL_ALIGNED


def test_T06_leakage_is_bounded_on_both_sides():
    """T-06: 頻率不對齊 bin 時洩漏必然存在——誤差雙邊有界（v1.2 實測校準）。"""
    spec = make_spec(main_freq_hz=137.0, noise_freq_hz=311.0, n_samples=256)
    b = generate(spec)
    filtered = suppress_tone(forward(b.noisy, spec.sample_rate_hz), spec.noise_freq_hz)
    err = rmse(reconstruct(filtered), b.clean)
    assert RTOL_LEAK_MIN * spec.main_amp < err < RTOL_LEAKY * spec.main_amp


def test_T12_suppress_does_not_mutate_input():
    """T-12: Spectrum 不可變。"""
    spec = make_spec()
    s = forward(generate(spec).noisy, spec.sample_rate_hz)
    before = s.coeffs.copy()
    suppress_tone(s, spec.noise_freq_hz)
    assert_allclose(s.coeffs, before, atol=0, rtol=0)
```
